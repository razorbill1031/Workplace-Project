# Workplace Project

회사 내부 업무 관리 시스템을 개발하는 개인 프로젝트입니다.

## 1단계 최종 목표

직원, 부서, 업무, 공지사항 및 회원 인증 기능을 포함한  
기본적인 회사 내부 업무 관리 시스템을 구현합니다.

## 개발 로드맵

### 현재 구현

- ① 프로젝트 기본 설정

### 구현 예정

- ② DB 연결
- ③ 직원 관리
- ④ 부서 관리
- ⑤ 업무 관리
- ⑥ 공지사항
- ⑦ 회원가입 / 로그인 / 로그아웃
- ⑧ 전체 기능 연결 및 테스트

## 기술 스택

- Java 21
- Spring Boot 4.1.1
- Gradle
- MySQL 26.7.0
- IntelliJ IDEA
